🔹 Hibernate Interview Questions & Answers (1–50)

What is Hibernate and why is it used?
==========================================
Hibernate is an ORM (Object Relational Mapping) framework for Java. It maps Java objects to relational database tables, reducing boilerplate JDBC code.

Eliminates need for writing SQL manually.

Provides CRUD operations via HQL or Criteria API.

Handles transaction management and caching.

Makes applications database-independent.

#########################################################################################################################

What are the main features of Hibernate?
==========================================

ORM support (object-table mapping).

HQL (Hibernate Query Language).

Automatic table generation.

Lazy loading and caching.

Transaction management.

Database independence.

#########################################################################################################################

What is ORM in Hibernate?
==========================================
ORM → Object Relational Mapping.

Maps Java classes to database tables.

Maps object fields to table columns.

Provides abstraction from JDBC and SQL.

#########################################################################################################################

What is the difference between JDBC and Hibernate?
==========================================

JDBC → Manual SQL queries, boilerplate code.

Hibernate → Uses HQL, automatic mapping, less code.

Feature	JDBC	Hibernate
SQL writing	Manual	Abstracted
Transactions	Manual	Automatic
Caching	No	Yes

#########################################################################################################################

What are Hibernate Annotations?
==========================================
Hibernate annotations replace XML configuration.

@Entity → Marks class as entity.

@Table → Maps class to DB table.

@Id, @GeneratedValue → Primary key.

@Column → Maps field to column.

#########################################################################################################################

What is the difference between Hibernate and JPA?
==========================================

JPA → Specification for ORM.

Hibernate → Implementation of JPA.

JPA defines APIs, Hibernate provides functionality.

#########################################################################################################################

What is Session in Hibernate?
==========================================
Session is the primary interface for database operations.

Provides methods for CRUD operations.

Wraps JDBC connection.

Not thread-safe.

#########################################################################################################################

What is SessionFactory in Hibernate?
==========================================
SessionFactory is a heavyweight object that creates Sessions.

Thread-safe and immutable.

Built once and shared across application.

Stores DB connection metadata and cache.

#########################################################################################################################

What is Transaction in Hibernate?
==========================================
Transaction ensures atomicity of database operations.

Either all operations succeed, or none.

Handled via beginTransaction(), commit(), rollback().

#########################################################################################################################

What is HQL in Hibernate?
==========================================
HQL → Hibernate Query Language.

Similar to SQL but works with objects not tables.

Example:

Query query = session.createQuery("from Employee where salary > :sal");


#########################################################################################################################

What is the difference between HQL and SQL?
==========================================

SQL → Works with tables and columns.

HQL → Works with objects and properties.

Feature	SQL	HQL
Syntax	Database dependent	Object oriented
Return	Rows	Objects

#########################################################################################################################

What is Criteria API in Hibernate?
==========================================
Criteria API allows dynamic query building in Java code.

Type-safe queries.

Example:

Criteria cr = session.createCriteria(Employee.class);
cr.add(Restrictions.gt("salary", 5000));


#########################################################################################################################

What are Named Queries in Hibernate?
==========================================
Predefined HQL queries defined with @NamedQuery.

Example:

@NamedQuery(name="Employee.byId", query="from Employee where id=:id")


#########################################################################################################################

What are the states of an object in Hibernate?
==========================================

Transient → Object not associated with DB.

Persistent → Object associated with session & DB.

Detached → Object once persistent, but session closed.

#########################################################################################################################

What is Lazy Loading in Hibernate?
==========================================
Lazy loading means data is loaded on demand.

Default fetching strategy in Hibernate.

Improves performance.

Example: relationships (@OneToMany(fetch=FetchType.LAZY)).

#########################################################################################################################

What is Eager Loading in Hibernate?
==========================================
Eager loading means data is loaded immediately with parent.

Defined using FetchType.EAGER.

Useful when related data is always required.

#########################################################################################################################

What is Caching in Hibernate?
==========================================
Caching improves performance by storing frequently accessed data.

First-level cache → Session scope.

Second-level cache → SessionFactory scope.

Providers: EhCache, Infinispan.

#########################################################################################################################

What is the difference between first-level and second-level cache in Hibernate?
==========================================

First-level cache → Mandatory, per session.

Second-level cache → Optional, shared across sessions.

#########################################################################################################################

What is Query Cache in Hibernate?
==========================================
Query cache stores results of queries.

Works with second-level cache.

Must be enabled explicitly.

#########################################################################################################################

What is the difference between save() and persist() in Hibernate?
==========================================

save() → Returns generated ID, works outside transaction.

persist() → Void return type, must be inside transaction.

#########################################################################################################################

What is the difference between get() and load() in Hibernate?
==========================================

get() → Returns object or null.

load() → Returns proxy, throws exception if not found.

#########################################################################################################################

What is the difference between merge() and update() in Hibernate?
==========================================

update() → Attaches detached object to session.

merge() → Copies changes into persistent object.

#########################################################################################################################

What are Hibernate Inheritance Mapping Strategies?
==========================================

Single Table (@Inheritance(strategy=SINGLE_TABLE)).

Joined Table (JOINED).

Table per Class (TABLE_PER_CLASS).

#########################################################################################################################

What is the difference between @OneToOne and @ManyToOne in Hibernate?
==========================================

@OneToOne → One entity associated with exactly one other.

@ManyToOne → Many entities linked to one entity.

#########################################################################################################################

What is @JoinColumn in Hibernate?
==========================================
Specifies the column used for a relationship.

Example:

@ManyToOne
@JoinColumn(name="dept_id")
private Department department;


#########################################################################################################################

What is the N+1 Select Problem in Hibernate?
==========================================
Occurs when one query retrieves parent entities, and additional queries fetch children.

Solved using fetch joins (JOIN FETCH).

#########################################################################################################################

What are Batch Updates in Hibernate?
==========================================
Batch updates group multiple SQL statements into one batch.

Improves performance for bulk inserts/updates.

Enabled with hibernate.jdbc.batch_size.

#########################################################################################################################

How to configure Hibernate with Spring Boot?
==========================================

Add spring-boot-starter-data-jpa.

Configure application.properties:

spring.datasource.url=jdbc:mysql://localhost:3306/test
spring.jpa.hibernate.ddl-auto=update


#########################################################################################################################

What is hibernate.cfg.xml?
==========================================
Configuration file for Hibernate (when not using Spring Boot).

Defines DB connection, dialect, mappings, caching.

#########################################################################################################################

What are Dialects in Hibernate?
==========================================
Dialect tells Hibernate how to convert HQL to SQL for specific DB.

Examples:

MySQL5Dialect

Oracle10gDialect

PostgreSQLDialect

#########################################################################################################################

What is Dirty Checking in Hibernate?
==========================================
Hibernate automatically detects changes in persistent objects and updates DB.

Saves developer from manually calling update().

#########################################################################################################################

What is the difference between Session.save() and Session.saveOrUpdate()?
==========================================

save() → Always inserts a new row.

saveOrUpdate() → Either saves new or updates existing.

#########################################################################################################################

What is StatelessSession in Hibernate?
==========================================
Lightweight session that does not provide caching or lifecycle management.

Useful for bulk operations.

#########################################################################################################################

What is HQL Injection?
==========================================
Similar to SQL injection but in HQL.

Prevented using parameterized queries (setParameter()).

#########################################################################################################################

What are native SQL queries in Hibernate?
==========================================
Allows execution of raw SQL inside Hibernate.

Example:

Query query = session.createSQLQuery("SELECT * FROM Employee");


#########################################################################################################################

What is the difference between @Embedded and @Embeddable?
==========================================

@Embeddable → Marks class as embeddable.

@Embedded → Used inside entity to include embeddable class.

#########################################################################################################################

What is the difference between @ElementCollection and @OneToMany?
==========================================

@ElementCollection → For storing collection of simple/embedded types.

@OneToMany → For mapping entities with relationships.

#########################################################################################################################

What is @Lob in Hibernate?
==========================================
Used for large objects (CLOB, BLOB).

Example: storing images, files, long text.

#########################################################################################################################

What is Optimistic Locking in Hibernate?
==========================================

Uses versioning (@Version).

Prevents overwriting data when multiple transactions update same row.

#########################################################################################################################

What is Pessimistic Locking in Hibernate?
==========================================

Locks row at DB level until transaction ends.

Ensures only one transaction modifies row.

#########################################################################################################################

What is @GeneratedValue in Hibernate?
==========================================
Specifies primary key generation strategy.

AUTO, IDENTITY, SEQUENCE, TABLE.

#########################################################################################################################

What is difference between save() and flush() in Hibernate?
==========================================

save() → Marks entity for persistence.

flush() → Synchronizes session with DB immediately.

#########################################################################################################################

What is evict() in Hibernate?
==========================================
Removes object from first-level cache.

Object becomes detached.

#########################################################################################################################

What is clear() in Hibernate?
==========================================
Clears entire first-level cache in session.

#########################################################################################################################

What is Session.close() in Hibernate?
==========================================

Closes session and releases DB connection.

Objects become detached.

#########################################################################################################################

What is @Temporal in Hibernate?
==========================================
Specifies how java.util.Date or Calendar should be stored.

DATE, TIME, TIMESTAMP.

#########################################################################################################################

What is difference between openSession() and getCurrentSession()?
==========================================

openSession() → Creates new session each time.

getCurrentSession() → Returns one session per transaction.

#########################################################################################################################

What is difference between save() and persist()?
==========================================

save() → Returns generated ID.

persist() → Returns void, follows JPA standard.

#########################################################################################################################

What are advantages of Hibernate?
==========================================

Reduces boilerplate JDBC code.

Database independent.

Caching support.

HQL + Criteria API.

Automatic table creation.

#########################################################################################################################

What are disadvantages of Hibernate?
==========================================

Steeper learning curve.

More memory usage than JDBC.

Debugging complex queries is harder.

Slower than plain JDBC in some cases.
